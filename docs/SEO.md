# SEO.md

Lenz Rescue. Keyword strategy, page map and the local search plan.

**Honesty note up front.** I have no access to a keyword volume tool, so there are no made up search
numbers in this file. What is here instead is the competitive picture I verified by searching, and
keywords grouped by buyer intent, which is what actually decides page structure. If you want volumes,
run this list through Keyword Planner or Ahrefs and the groupings still hold.

---

## 1. What the search results actually look like

I searched the real queries. The finding is worth more than any volume number:

**There is almost no real competition in this market.** Page one for headlight restoration around
East Contra Costa is made up of directory listings, not businesses:

- BBB category pages for Brentwood, Pittsburg and Bay Point
- MechanicAdvisor listing pages for Concord, Oakland, Hayward, Vallejo
- Google Sites pages, Squarespace trial subdomains, `pages.dev` and `vercel.app` throwaways
- Thumbtack's national "headlight restoration cost" page
- Glass Doctor, the one national brand with a real site

Not a single local operator with a proper site owning their own city. That is unusual and it will not
last. A real site with real location pages and a real Google profile can take these positions inside
a few months, because the bar is on the floor.

**The second finding.** The highest intent queries are about **price**, and the only page ranking for
them is Thumbtack, which is a lead marketplace, not a business. "How much is mobile headlight
restoration" is a person with a wallet out. Owning that query locally is the single biggest
opportunity on this list.

## 2. Keywords by intent

Primary term throughout: **headlight restoration**. Secondary: **mobile headlight restoration**.
Do not optimise for "headlight cleaning" or "headlight polishing" as the main term. People search
them, but "restoration" is the industry and buyer word, and the other two can live as variants
inside body copy.

### Tier 1: money keywords, local, buy now

These go on dedicated pages. One page, one city, no exceptions.

```
headlight restoration antioch ca
headlight restoration brentwood ca
headlight restoration pittsburg ca
headlight restoration oakley ca
mobile headlight restoration near me
headlight restoration near me
```

### Tier 2: price and decision, highest intent, nobody local owns them

This is the gap. Each of these deserves a real answer with a real number on the page.

```
headlight restoration cost
how much does headlight restoration cost
mobile headlight restoration cost
headlight restoration price
is headlight restoration worth it
how long does headlight restoration last
headlight restoration vs replacement
headlight restoration vs new headlights
professional headlight restoration vs diy kit
```

### Tier 3: problem aware, the top of the funnel

The person does not know the service exists yet. They know their lights look bad.

```
why are my headlights foggy
how to fix cloudy headlights
yellow headlights how to fix
hazy headlights
oxidized headlights
headlights dim at night
can foggy headlights be fixed
```

### Tier 4: the add on services, new as of the client's message

These are their own pages. Almost nobody writes about marker and tail lights, which makes them
cheap to rank for.

```
fog light restoration
tail light restoration
marker light restoration
headlight and tail light restoration
faded tail lights fix
cloudy fog lights
```

### Tier 5: trade and volume

Different buyer, different page, different language.

```
dealer headlight restoration
auction vehicle reconditioning headlights
fleet headlight restoration
mobile reconditioning dealership
wholesale headlight restoration
```

### Words to avoid

- **Anything implying a safety inspection requirement.** California has smog check, not a general
  vehicle safety inspection. Do not write "pass inspection" or imply a legal failure. It is false and
  it will eventually cost trust.
- "Cheap", "discount", "lowest price". This business sells the fourth step. Competing on cheap
  invites comparison with a thirty dollar kit, which is the argument we want to win, not join.
- "Near me" stuffed into body copy. Google handles proximity. Writing "headlight restoration near me
  in Antioch" reads as spam to a human and buys nothing.

## 5. On page rules

1. **One H1 per page**, containing the primary keyword naturally. The home page H1 is "Bring clarity
   back to the road", which contains no keyword at all. That is fine and deliberate, because the
   title tag and the H2s carry it. Do not ruin a good headline for a keyword.
2. The primary keyword appears in the **first 100 words** of body copy, once, in a normal sentence.
3. H2s cover the questions people actually ask. On the cost page the H2s literally are
   "What does it cost", "What changes the price", "How long does it last", "Is it worth it versus new
   headlights".
4. **Every page ends with a next step**, not a dead end. The guide links to the cost page, the cost
   page links to the gallery, the gallery links to contact.
5. Image alt text carries the vehicle and the city, as already specified in CONTENT.md section 9.
   Alt text is a real ranking input for image search, and image search matters for a before and after
   business.
6. **No keyword stuffing anywhere.** If a sentence would embarrass you read aloud, it is stuffed.

## 6. Google Business Profile, the biggest single lever

For a mobile local service, the Google profile outranks the website for most commercial searches.
Everything below is free and most of it takes an afternoon.

**Set up correctly**
- Service area business, **no street address shown**. Set the service area to Antioch, Brentwood,
  Pittsburg, Oakley, plus Discovery Bay, Bay Point and Knightsen if they genuinely serve them.
- Primary category: **Car detailing service**. There is no "headlight restoration" category.
  Secondary: Auto restoration service, Auto glass shop if it fits.
- Services list: add every one by name, Headlight restoration, Fog light restoration, Tail light
  restoration, Marker light restoration, Dealer reconditioning. Each gets its own description with
  the price.
- Hours must be filled in. Blank hours suppress the profile.
- Link the website, and link each service to its matching page.

**Then the part that actually moves the ranking**
- **Reviews.** The site currently shows zero. This is the number one limiting factor on the whole
  business, bigger than any design or technical fix. Ask every single customer, the same day, with a
  direct link, by text. Ten real reviews mentioning the city name will do more than ten blog posts.
- **Photos.** Upload every before and after pair to the profile, not just the site. Geotag where
  possible. Google surfaces these in local results and they get clicked.
- **Posts.** One a week, fifty words, with a photo. A finished job, a price note, a seasonal tip.
  Low effort, and an active profile outranks a dormant one.
- **Q and A.** Seed it yourself. Ask and answer "How much does it cost", "Do you come to me", "How
  long does it last". These show in the local panel.

## 7. Schema

JSON-LD on every page.

- `AutoRepair` extending `LocalBusiness` on every page: name, telephone, email, `areaServed` as four
  `City` entries, `GeoCircle` for the radius, `priceRange: "$$"`, `sameAs` for Facebook and
  Instagram, **no `address`** since there is no storefront. Add `aggregateRating` the moment real
  reviews exist, and not before. Fake review markup is a manual penalty.
- `Service` on each service page with `provider`, `areaServed`, and `offers.priceSpecification` with
  `minPrice: 125`, `priceCurrency: "USD"`.
- `FAQPage` on `/headlight-restoration-cost` and `/vehicle-guide`. These are the two pages most
  likely to win a rich result.
- `BreadcrumbList` on everything below the home page.
- `ImageObject` on the gallery pairs with real captions.

## 8. Technical

The old site's problems, and what must be true instead.

| Was wrong | Must be |
|---|---|
| `/sitemap.xml` returned the homepage HTML, a soft 404 | Real XML sitemap listing every route |
| No robots.txt | Real robots.txt pointing at the sitemap |
| One page, no location pages | Fourteen routes as mapped above |
| Same generic alt on all five photos | Unique descriptive alt on every image |
| No structured data at all | Section 7 above |
| No og:image, so every share preview was blank | `og:image` on every page, 1200 x 630, with the before and after pair on it |
| Images not reachable to automated clients | Verify every image returns a real 200 to a plain request |
| Logo as JPEG | SVG |

Core Web Vitals targets are already in MOTION.md section 9. The one SEO specific addition: the
hero image must be the LCP element and must be preloaded. A WebGL canvas that paints before the text
will wreck LCP if the poster is not preloaded.

## 9. The content that earns the rankings

In priority order. Do not write all of these at once.

1. **`/headlight-restoration-cost`.** Write it first. Real numbers, what changes the price, how it
   compares to a new assembly, how long it lasts, when it is not worth it. This page is the one that
   will bring in work.
2. **The four city pages.** Genuinely different, as specified in CONTENT.md section 8.
3. **`/vehicle-guide`.** Already strong. It is the page most likely to get linked to, because it
   tells people when not to buy.
4. **Tail and marker light pages.** Thin competition, quick wins.
5. Later, if there is appetite: one guide on "why headlights go yellow and what actually fixes it",
   aimed at Tier 3. One article, done properly, beats ten thin ones.

## 10. What to measure

Set up Search Console on day one, before launch. Then check monthly, not daily.

- Impressions and clicks for each of the four city terms
- Position for "headlight restoration cost" and the mobile variants
- Google Business Profile: calls, direction requests, website clicks
- Review count and average rating, tracked as a number that must go up every month
- Which page the phone calls actually come from, using a distinct tracked link per page if possible

Realistic timeline, stated plainly so nobody is disappointed: the Google profile can produce calls in
**two to four weeks** if reviews start coming in. The city pages take **three to six months** to
settle. The cost page can rank faster than the city pages because the competition is a directory.
